# scripts/

Scripts **simples e pontuais** de manutenção do repositório (ex.: tarefas de
conveniência local, checagens rápidas).

Diferente de `tooling/`, que hospeda automação durável de qualidade de produto.
Se um script aqui amadurecer e virar automação recorrente de governança, ele
deve migrar para `@britus/tooling`.

> **Estado atual:** vazio. Nenhum script criado nesta etapa.
