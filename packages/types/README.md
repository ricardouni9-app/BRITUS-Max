# @britus/types

Tipos **compartilhados** entre os apps e demais pacotes da BRITUS Platform
(ex.: modelos de domínio e contratos de API).

Fonte única de verdade para tipos que cruzam fronteiras de módulo — evita
duplicação e divergência (alinhado ao Princípio da Captura Única).
