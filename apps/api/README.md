# @britus/api

Aplicação **de backend** (API) da BRITUS Platform.

## Stack pretendida (a materializar quando a Sprint 1 for especificada)

- Runtime: Node.js (padrão 24 LTS)
- Linguagem: TypeScript
- Capacidade de persistência: PostgreSQL (utilidade atual: a definir — ex. Neon)

> **Estado atual:** apenas o espaço estrutural do app. Nenhuma rota, banco, ORM,
> autenticação ou integração foi criada nesta etapa (proibido pela Etapa 5).
> Estas capacidades dependem de especificação técnica posterior.
