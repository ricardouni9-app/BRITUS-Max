# @britus/web

Aplicação **web** (frontend) da BRITUS Platform.

## Stack pretendida (a materializar quando a Sprint 1 for especificada)

- Build/dev: Vite (utilidade atual)

> **Estado atual:** apenas o espaço estrutural do app. Nenhuma tela, componente
> de negócio ou dependência foi instalada nesta etapa (Engineering Just-in-Time).
> O scaffold funcional será criado quando a Sprint 1 (Núcleo Operacional) for
> especificada tecnicamente.
